Review Notes 0.1.0 (step 1) - notes drawn and written on a camera and frames, like SyncSketch, inside Maya.
A separate tool, next to the onion skin; both show at the same time.

STEP 1 = THE NOTES SHOW. There are no drawing tools yet (step 2) and no notes window yet (step 3): to try it,
add a sample note from the Script Editor (below).

INSTALL OR UPDATE (every new version the same way)
1. Get the scripts/review_notes folder (with drag_to_maya.mel and the reviewNotes folder inside).
2. Drag drag_to_maya.mel into Maya's viewport. It installs (or updates) Review Notes, puts one "Review" button
   on the shelf you have open and loads the plugin. From then on: click Review.

WHERE THE NOTES ARE KEPT
- In a file next to your scene: sh010_anim_v012.ma -> sh010_anim.review.json. The _v012 is left out, so the
  notes follow you when you version up (each note remembers which version it was made on).
- Nothing is saved inside the scene. The REVIEW_NOTES node only shows the notes; it's never saved, and opening
  a scene that has a review file next to it shows its notes by itself.
- A scene that was never saved has no notes: save it first.

TRY IT (step 1)
1. Open a scene, save it once, click in your shot camera's view.
2. Click Review. The message says how many notes the scene has.
3. Add a sample note (red arc + arrow) on this camera, from this frame for 6 frames - Script Editor, Python:
       import reviewNotes.controller as rn; rn.sample()
   Run it again on another frame or camera for more notes.
4. Scrub: the note shows on its frames, faint orange before them, faint blue after, only through its camera.
5. Settings: select REVIEW_NOTES (Outliner) > Attribute Editor: Show Nearby, Nearby Frames, Only Open,
   Show Text, Opacity, Hide While Playing, Show Gate (the try-it's green box).
6. Show menu > Review notes hides / shows them in one view.

SELF TEST (in a NEW, EMPTY scene - paste the lines it prints)
       import reviewNotes.selftest as t; t.run()

TESTS OUTSIDE MAYA (for development)
       python3 scripts/review_notes/tests/test_review_notes.py
