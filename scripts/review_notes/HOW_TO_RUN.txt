Review Notes 0.2.3 - notes drawn and written on a camera and frames, like SyncSketch, inside Maya.
A separate tool, next to the onion skin; both show at the same time.

INSTALL OR UPDATE (every new version the same way)
1. Get the scripts/review_notes folder (with drag_to_maya.mel and the reviewNotes folder inside).
2. Drag drag_to_maya.mel into Maya's viewport. It installs (or updates) Review Notes, puts one "Review" button
   on the shelf you have open and loads the plugin. From then on: click Review.

WHERE THE NOTES ARE KEPT
- In a file next to your scene: sh010_anim_v012.ma -> sh010_anim.review.json. The _v012 is left out, so the
  notes follow you when you version up (each note remembers which version it was made on).
- Nothing is saved inside the scene. The REVIEW_NOTES node only shows the notes: it's taken out just before
  every save (or export) and put back right after, with its settings, so a scene you send to someone without
  Review Notes opens clean. Opening a scene that has a review file next to it shows its notes by itself.
- If the installer ends with "RESTART MAYA", do: the plugin running is an older one until Maya restarts.
- A scene that was never saved has no notes: save it first.

DRAW A NOTE
1. Save your scene once (the notes go in a file next to it). Click Review on the shelf: the window opens.
2. Click "Draw on the view" (or Pen / Curve / ... ), then draw in the view you want the note on. Alt still
   moves the camera. The drawing belongs to the camera and frame where you start it.
   - Pen: drag. Arrow: drag from tail to head. Circle: drag across its box.
   - Curve (like Illustrator): click = corner, click-drag = smooth point; click the first point to close;
     drag points or handles to adjust, Ctrl-drag breaks a handle. Enter (or a double-click) ends it, Esc
     throws it away.
   - Eraser: rub over lines - only the part under it goes (Size sets how big). Works on the drawing and on
     saved notes on this frame (the review file's .bak keeps the version from before you started).
3. Write what should change, pick the type (change / fix / add / idea) and for how many frames it shows
   (1 = only this frame, the default). The drawing stays on its frame until you save it.
4. Save note (Enter in the view, Ctrl+Enter in the window). Clear (or Esc) throws the drawing away.

THE NOTES
- The list shows every note of the scene: double-click (or Go to) = its frame, through its camera.
  Status: open > in progress > done. Delete removes it from the file. Filter: All / Open / This camera.
- Nearby: notes a few frames before / after show faint (orange coming, blue passed). Only open: done notes hidden.
- Opacity (slider in the window): how strong the notes look in the view.
- More settings on REVIEW_NOTES (Outliner) > Attribute Editor. Show > Review notes hides them in one view.
- Hotkeys: Hotkey Editor > Custom Scripts > Review Notes (draw on / off, save, end curve) - give them keys.

SYNCSKETCH (coming: notes from a SyncSketch review shown on your camera)
- First, one real sample: in the Terminal, run
       "/Applications/Autodesk/maya2024/Maya.app/Contents/bin/mayapy" ~/Downloads/review_notes/syncsketch_sample.py
  (use the folder you unzipped to). It asks for your SyncSketch user name and API key (Settings > Developer
  Options) once, keeps them in ~/.review_notes_syncsketch.json, then saves one video's notes to your Desktop.
  SyncSketch's API needs an Enterprise account.

SELF TEST (in a NEW, EMPTY scene - paste the lines it prints)
       import reviewNotes.selftest as t; t.run()

TESTS OUTSIDE MAYA (for development)
       python3 scripts/review_notes/tests/test_review_notes.py
