Add / remove inbetween
- Add: every key after the current frame moves later by the step; Remove: the frames after the current one go and
  the rest moves earlier. Step 1 / 2 / 3 / 5 / 10. On: selected controls, the whole character, or everything

Offset with 'back to original'
- Offset - / +: every key of the selected controls moves by the step - all the same, or cascade (select base to
  tip: the first stays, each next one a step more).
- Back to original: the timing from before any offset comes back (remembered in the scene, so it survives saving

Gus Animtool 2.1.0

Graph Editor keys (Keys tab) - ideas from Aaron Koressel's ackPushPull / ackNegateKeys / ackDeleteRedundant,
written again in Python
- Pull: the selected keys' values move towards the pivot key (softer). Push: away from it (bigger).
- Negate: the selected keys flipped upside down around the pivot key (the opposite pose / motion).
- Delete redundant: among the selected keys, the ones with the same value as both neighbours go.
- Each curve is worked on its own. Pivot (dropdown): the key on the left, on the right, or the last selected
  key. Factor (dropdown): 0.95, 0.9, 0.8, 0.75, 0.5.

Hotkeys (Settings, off until you turn them on)
- Alt+- pull, Alt+= push, Alt+Shift+- negate (with the nudge / tween ones). All of them are also in the Hotkey
  Editor > Custom Scripts > Gus Animtool, so you can bind your own keys there.

Temporary spaces (Space tab)
- World: a locator per selected control follows it over the frame range (baked), then the control follows the
  locator - animate in world space.
- Camera: the same, seen from the camera you look through (arcs, screen spacing).
- Pivot: a locator at the control - move it, then turn it to rotate around a new pivot.
- Bake back: the controls keep the motion as keys over the range; the helpers are deleted.

Selection sets (Pick tab)
- Your own groups of controls (mouth, L hand...), saved in the rig profile - every scene with this rig has them,
  whatever the namespace. Save, Select (or double-click), Add, Remove.

Rotate order (Keys tab)
- The selected controls get a new rotate order; their rotation keys are re-made so the motion doesn't change
  (Euler filter after). Without keys, the pose stays.

Decisions I made (tell me to change any)
- Default pivot: the key on the left; default factor 0.9 (like the ack scripts).
- Push divides by the factor, so a pull then a push gets you back where you were.
- Delete redundant tolerance: 0.00001.
- Temporary spaces bake over the frame range in the header; locked channels are skipped.
- Selection sets store names without namespace.
